# script-runner

A desktop app for registering personal scripts and running them from one place.
Scripts run unmodified inside an embedded terminal, so interactive prompts (for example
Python's `input()`) and colored output work as usual.

Built with Tauri 2, React, TypeScript and Vite. Targets Linux, Windows and macOS
(desktop only: mobile platforms cannot run local interpreters).

> Status: early development. The UI shell (theme, language, settings) is in place;
> the script features below are planned.

## Planned features

1. Run a script in an embedded terminal and answer its prompts
2. Script registry: add, edit and remove scripts (name, path, interpreter, working directory,
   arguments, description), stored as JSON
3. Run from the registry: interpreter detection, working directory, stop button, exit code display
4. Sequences: run an ordered list of scripts, each starting only if the previous one exited with code 0
5. Polish: run history, English and Turkish UI, packages for Linux, Windows and macOS

Scripts are local files chosen by the user. The app never fetches or runs remote code.
Interpreters are not bundled and must be installed on the machine
(for example Python, bash or PowerShell).

## Tech stack

- Tauri 2 (Rust backend), React, TypeScript, Vite
- Tailwind CSS 4 and shadcn/ui (Base UI, Nova preset)
- i18next with English and Turkish
- Light / dark / system theme (class-based, `.dark` on `<html>`)
- Settings panel (gear icon in the top right), persisted in `localStorage` (`app-settings` key)

## Project layout

- `src/shadcn/` holds everything generated by the shadcn CLI (see `components.json`)
- `src/components/`, `src/lib/`, `src/settings/`, `src/i18n/` hold our own code
- `src/i18n/locales/` holds translation files (keep keys identical in every language)
- `src-tauri/` is the Rust side

## Setup

- Tauri system dependencies for your OS: see https://v2.tauri.app/start/prerequisites/
- Rust via `rustup`, Node.js with npm
- Linux on Wayland: WebKitGTK may crash without this workaround (fish shell):

```fish
set -Ux WEBKIT_DISABLE_DMABUF_RENDERER 1
```

## Development

```bash
npm install
npm run tauri dev
```

## Known notes

- `npm audit` reports high severity warnings coming from the shadcn CLI dependency chain.
  They affect development tooling only and are not bundled into the app.
- shadcn/ui is based on Base UI here, so component APIs differ from the Radix versions.
  Check the generated files in `src/shadcn/ui/` before using a new component.
- `src/shadcn/ui/sheet.tsx` is edited by hand: the close button position includes
  `env(safe-area-inset-*)`. Re-adding the component with `--overwrite` removes this change.
