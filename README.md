# script-runner

A starter template for cross-platform apps built with Tauri 2, React, TypeScript and Vite.
Targets Linux, Windows, macOS, Android and iOS from a single codebase.

## What is included

- Tauri 2 (Rust backend), React, TypeScript, Vite
- Tailwind CSS 4 and shadcn/ui (Base UI, Nova preset)
- Light / dark / system theme (class-based, `.dark` on `<html>`)
- i18next with English and Turkish (language is detected from the device on first launch)
- Settings panel opened from a gear icon in the top right
- Settings persisted in `localStorage` (single `app-settings` key)
- Responsive and touch-friendly layout with safe-area support for phones
- Empty main area (`<main>` in `src/App.tsx`) for each app to fill in

## Project layout

- `src/shadcn/` holds everything generated by the shadcn CLI (see `components.json`)
- `src/components/`, `src/lib/`, `src/settings/`, `src/i18n/` hold our own code
- `src/i18n/locales/` holds translation files (keep keys identical in every language)
- `src-tauri/` is the Rust side; `src-tauri/gen/android/` is the generated Android project

## One-time machine setup (CachyOS / Arch)

- Tauri system dependencies: see https://v2.tauri.app/start/prerequisites/
- Rust via `rustup`, plus the Android targets:

```bash
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
```

- Android Studio from the AUR (`paru -S android-studio`), then install these in the SDK Manager:
  Build-Tools, Command-line Tools, Platform-Tools, NDK (Side by side)
- Environment variables (fish shell, adjust the NDK version):

```fish
set -Ux JAVA_HOME /opt/android-studio/jbr
set -Ux ANDROID_HOME $HOME/Android/Sdk
set -Ux NDK_HOME $HOME/Android/Sdk/ndk/<ndk-version>
```

- Wayland and WebKitGTK crash workaround:

```fish
set -Ux WEBKIT_DISABLE_DMABUF_RENDERER 1
```

- Firewall: let the phone reach the dev server (UFW, adjust your subnet):

```bash
sudo ufw allow from 192.168.1.0/24 to any port 1420 proto tcp comment 'Tauri dev server'
```

iOS builds need macOS and Xcode and cannot be done on Linux.

## Creating a new app from this template

1. Copy the folder without build output and Git history:

```bash
rsync -a --exclude .git --exclude node_modules --exclude dist \
  --exclude src-tauri/target --exclude src-tauri/gen/android/build \
  --exclude src-tauri/gen/android/.gradle ./script-runner/ ./my-app/
```

2. Rename the app in all of these places:
   - `package.json`: `name`
   - `index.html`: `<title>`
   - `src-tauri/tauri.conf.json`: `productName`, `identifier`, window `title`
   - `src-tauri/Cargo.toml`: package `name` and `[lib]` `name`
   - `src-tauri/src/main.rs`: the `<lib name>::run()` call must match the `[lib]` name
3. The `identifier` becomes the Android package name. Use `com.yourname.appname`:
   all lowercase, no hyphens, not ending in `.app`.
4. Regenerate the Android project so the new identifier is used:

```bash
rm -r src-tauri/gen/android
npm install
npm run tauri android init
```

5. Replace the app icon: `npm run tauri icon path/to/icon.png`
6. Put the app's UI inside `<main>` in `src/App.tsx` and add its texts to both locale files.

## Development

```bash
npm run tauri dev            # desktop
npm run tauri android dev    # Android phone over USB (same Wi-Fi as the PC, see firewall note)
```

If the phone shows a connection error, open `http://<pc-ip>:1420` in the phone browser to test the network path.

## Known notes

- `npm audit` reports high severity warnings coming from the shadcn CLI dependency chain.
  They affect development tooling only and are not bundled into the app.
- shadcn/ui is based on Base UI here, so component APIs differ from the Radix versions.
  Check the generated files in `src/shadcn/ui/` before using a new component.
- `src/shadcn/ui/sheet.tsx` is edited by hand: the close button position includes
  `env(safe-area-inset-*)` so it stays below the status bar on phones.
  Re-adding the component with `--overwrite` removes this change.
