## This app

Goal: a desktop GUI where I register my personal scripts (mostly Python, some in other languages) and run them from one place. Example flow from my Minecraft server: extract all zipped logs into one `.log`, filter IPs of players who attempted unauthorized logins, write the IPs to a `.txt`, remove duplicate IPs. Some scripts ask questions with `input()` (log folder path, output file name and location) and I must be able to answer them inside the app.

### Decisions already made

- Desktop only (Linux, Windows, macOS). No Android or iOS, because mobile cannot run local interpreters. Never run `tauri android init` or `tauri ios init` for this app.
- Scripts run as-is inside an embedded real terminal (pseudo-terminal), so `input()` and colors work with unmodified scripts. Plan: PTY on the Rust side (`portable-pty` crate, verify) plus xterm.js in React, streaming output through Tauri events or channels (verify).
- Scripts are local files chosen by me; the app never fetches or runs remote code. Keep Tauri capabilities minimal and prefer our own Rust commands over a broad shell plugin scope (verify which fits).
- Chaining: v1 runs single scripts. Next come "sequences": an ordered list of scripts run one after another in the terminal; the next one starts only if the previous exited with code 0, and I answer prompts as usual. Automatic output-to-input data wiring is a later idea (it needs declared parameters and conflicts with running scripts as-is).

### Milestones

Propose a detailed breakdown before starting each milestone.

1. Run one hard-coded script in an embedded terminal and answer its prompts.
2. Script registry: add/edit/remove scripts (name, path, interpreter, working directory, args, description), file picker via the Tauri dialog plugin, stored as JSON (decide: Rust-side file in the app data dir vs Tauri store plugin).
3. Run from the registry: interpreter detection (python3 vs py on Windows), working directory, stop button, exit code display.
4. Sequences.
5. Polish: run history, Turkish/English UI texts, packaging for Linux, Windows and macOS.
